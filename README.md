# SprintWorks website

A responsive, single-page SprintWorks website with a compass hero, story, problem selector, career-compass approach, About section, events, and enquiry form.

## Deploy (recommended: Netlify)
1. Go to https://app.netlify.com/drop and sign in.
2. Unzip the downloaded `sprintworks-site.zip` file.
3. Drag the `sprintworks-site` folder (or the unzipped folder contents) into Netlify Drop.
4. Once deployed, submit a test enquiry. Netlify may need to detect/enable Forms for the site; check **Forms** in the Netlify dashboard and enable form detection if prompted, then redeploy.
5. Check the **sprintworks-enquiry** form in Netlify Forms to view submissions.

## Important before public launch
- Verify event dates and whether registrations are open: Nov 28, 2026; Dec 28, 2026; Jan 30, 2027.
- Add your approved privacy policy and terms links/content.
- Add official contact details and social links if desired.
- This is a static front-end. The enquiry form uses Netlify Forms markup and works when deployed/configured on Netlify. If you deploy elsewhere, connect the form to that host's form endpoint/service.
- Test on desktop and mobile and send a test submission before sharing the public link.
