# SprintWorks — conversion-focused website update

This version adds audience-specific messaging, an Academic Direction Expert (ADE) contact path, an interest form, clearer event CTAs, a transparent four-step guidance process, FAQs, and explicit notes about what is not yet finalised.

## Before publishing
1. **Connect the lead form to a real, secure submission endpoint** (CRM or form service) and test delivery, error states, consent, and spam protection. The current form validates in the browser but intentionally does not pretend to submit or store data.
2. Confirm the official contact email, phone/WhatsApp number, privacy notice and data-retention process.
3. Confirm event times, webinar platform, in-person venue and registration cap.
4. Finalise the January 2027 cohort curriculum, format, duration, price, cancellation/refund terms and what participants receive. Do not accept payment until these are published.
5. Add verified ADE/team profiles, qualifications and consented testimonials only when available. No invented outcomes or guarantees are included.
6. Run desktop/mobile browser QA and keyboard/accessibility checks before launch.

## Main conversion path
Audience fit → explain the process → choose webinar / parent–student meet / cohort updates / ADE → submit interest form → human follow-up.

## Important
The form currently shows an explicit not-connected status on submit. It is a front-end prototype until a real endpoint is integrated.
